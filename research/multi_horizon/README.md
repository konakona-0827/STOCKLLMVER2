# 台股多期限離線研究入口

對應[改造計畫](../../docs/experiments/TW_MULTI_HORIZON_PLAN.md) M0。此工具產生歷史價格路徑標籤及成本情境，尚無選股模型、機率校準、資金配置或模擬帳戶。只使用 Python 標準函式庫，不載入 `.env` 或正式交易設定。

從 `STOCKLLM` 程式目錄執行合成範例：

```powershell
python -m research.multi_horizon `
  --bars research/multi_horizon/examples/synthetic_bars.csv `
  --sessions research/multi_horizon/examples/synthetic_sessions.csv `
  --dataset-note 'SYNTHETIC：虛構 DEMO 股票與價格，僅驗證流程，非市場資料'
```

命令輸出結果目錄，例如 `research-runs/<run_id>/`。每次建立獨立目錄，不覆寫舊結果。參數 `--protocol` 可選擇另一版 JSON；`--output-root` 可指定輸出根目錄，預設相對目前工作目錄。實際研究請先複製並修改協議，固定成本假設與資料期間後再執行。

## 輸入

日線 CSV 必須有 `symbol,date,open,high,low,close,volume`，日期為 ISO `YYYY-MM-DD`，OHLC 必須是有限正數且高低關係正確，成交量是非負整數股數。股票代碼以文字保留前導零。檔案允許不排序，重複股票日期會被拒絕。

交易日 CSV 只有 `date` 欄，需遞增且不重複，必須由實際交易所日曆準備。每檔股票第一至最後一筆之間都必須覆蓋日曆交易日。停牌可保留正數參考價格、`volume=0`，工具會標記需要覆核；不能直接刪除停牌日。工具能檢查資料是否符合所提供的日曆，不能自動判定日曆本身是否正確。

`--dataset-note` 必填，記錄來源、股票歷史母體、價格調整、公司行動與排除規則。工具不自動取得歷史成分或除權息；不同價格基準不得混接。預設商品是一般股票；ETF 等不同稅別須另立協議與實作。

## 標籤定義

- 每個已提供日線收盤都當作假想訊號，下一個交易日的開盤作為情境進場價，另加買方滑價。
- 最早在買入後下一交易日退出。`horizon_trading_days=5` 指**買入日後五個交易日**，買入日不計入視窗；週末與休市依輸入日曆排除。
- 停利／停損門檻以含買方滑價的進場價計算。跳空跌破停損使用較差開盤價；跳空超過停利僅給目標價。開盤已觸價時順序已知，先處理開盤。
- 開盤介於門檻之內、同一日高低都碰到停利停損時，採停損先發生，`ambiguous_bar=True`。這是日線資料不足時的保守假設。
- 未觸價且完整到期，使用期末收盤扣賣方滑價。C 的 null/null 障礙只產生長期到期價格基準。
- 沒有足夠未來資料且尚未退出，標為 `CENSORED`，損益留空。進場日零量或連最低費用都無法負擔，標為 `NOT_ENTERED`；途中零量會中止並要求覆核。
- 如果部分未來資料已確定觸價，可以保存 `COMPLETE` 標籤；但 `window_complete=False` 的提早退出樣本會從摘要統計排除。否則資料尾端會只納入已觸價者，形成偏差。

日線高低、開盤和收盤不是盤中零股可成交報價；價格門檻與滑價也未按實際跳動單位撮合。漲跌停排隊、價差、成交深度、部分成交、委託有效日及公司行動尚未模擬。輸出是價格路徑情境，不能視為真實成交。

## 輸出與解讀

| 檔案 | 用途 |
| --- | --- |
| `bars.csv`、`sessions.csv`、`protocol.json` | 實際執行使用的原始位元組快照 |
| `labels.csv` | A/B/C 各期限、各障礙的逐筆標籤與成本後情境損益 |
| `summary.json` | 每條研究線／期限／障礙的樣本數、描述性頻率與情境資金效率 |
| `run.json` | 唯一 run ID、資料說明、資料及實作 SHA256、假設與限制 |

每組摘要的 `complete` 是有確定退出結果的標籤數，`evaluated` 才是完整觀察視窗且可進入統計的數量；`partial_window_exits_excluded` 記錄被排除的未成熟視窗退出結果。`censored`、`not_entered` 分別列示。零量或其他排除也可能改變樣本組成，必須檢查排除原因。

`empirical_tp_fraction` 是成熟完整樣本的描述性比例，並非個股未來機率。C 的價格基準沒有停利機率，此欄為 null。

`scenario_pnl_per_10000_capital_day = Σ情境淨損益 ÷ Σ(買入含費成本 × 持有交易日) × 10000`。這只比較逐筆機會的價格／成本情境。每日機會可能重疊；沒有扣除組合資金上限、T+2 或 API 費用，不代表可達成的帳戶日收益。本工具不產生年化報酬、資產曲線、最大回撤或策略優勝結論。

A／B／C 各自保留分線標籤與摘要；真正獨立的模擬帳戶尚待 M2／M3 實作。C 的範例視窗全部未成熟，是合成資料只有 12 個交易日的正常結果。

```powershell
python -m unittest discover -s tests -p test_multi_horizon_research.py -v
```
