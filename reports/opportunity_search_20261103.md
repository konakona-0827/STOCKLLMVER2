# 2026-11-03 主動尋找買進機會與研究成本改善

已套用 `strategy_opportunity_v1`，runtime 為 `agent-decision-v5-opportunity-search`。本次不再只分析為什麼不買，而是把可執行的進場計畫生成、候選選擇、模型研究與成本控制接成完整流程。

## 核對現況

11/3 日本時間約 13:06，中信金 2891 的 25 股 SELL 已在正式帳本確認 FILLED。修改前帳本有 24 筆委託嘗試，剩餘 AI 持股為台泥 1101 共 99 股。這次工作聚焦新買機會，未補送歷史委託、未新增試單或每日交易次數目標。

## 核心調整

| 環節 | 原流程 | 新流程 |
|---|---|---|
| 研究範圍 | 先取量價前 10 名，再問是否值得買 | 既有完整 20 檔研究池先算可執行計畫，再挑最多 3 個研究候選；AI 持倉另保留 |
| 佣金與現金 | 20 元資金保留同時當成每側最低佣金 | 現金仍至少保留 20 元；佣金獨立參數，以公開電子零股最低 1 元、未折扣 0.1425% 估算 |
| 倉位基準 | 剩餘現金再乘 15/25/30%，容易重複縮量 | 固定 AI 資金上限的 15/25/30%，先扣同檔既有曝光，再受真正可用現金限制 |
| 訊號與價位 | 所有價位與許多日線高點都被當作近端上限 | 區分結構支撐、結構阻力與盤中小高低；趨勢與區間策略採不同目標依據 |
| 創高後目標 | 沒有更高歷史價位便無法形成買單 | 已完成日線突破及量能條件成立、沒有更高結構阻力時，允許明示為模型估算的 2R 情境，受 4ATR 上限限制 |
| 研究順序 | 每輪對多檔重述觀望 | 先數字與結構計畫，研究優先候選；有具體反證才否決，不要求先證明未來必定上漲 |
| 重複 API | 相近行情重問同一決策 | 新計畫、帳戶變化、價格明顯變化或風險觸發才優先喚醒；未變條件可略過付費分析 |

新策略與舊策略分成不同檔案，原始 `strategy_support_scout_v1.md` 保留。正式選擇記錄在 `data/analysis/live_strategy.json`。

## 如何主動生成機會

`opportunity_engine.py` 在本機完成：

1. 核對 LIVE 非試撮行情、研究池歸屬、資金、冷卻期、虧損持倉不加碼及未結委託。
2. 檢查實際連續的已完成交易日日線，計算 MA5/20、ATR14、完成日線量能及局部結構高低。未來日線不參與判斷，不把當日累計零股量冒充完成日線成交量。
3. 產生現價、支撐回落、前收／開盤或明示為均線參考的限價路徑。回落距離限制在 1ATR 與 3% 之內，避免用很遠、當日難以執行的價格製造機會。
4. 按 Early／Confirmed／Strong 對應的真實訊號條件配置。停損必須有觀測支撐或已完成日線低點依據，與入場保留至少 0.6ATR 及兩倍目前價差，不為得到較大股數而貼近停損。
5. 順序核算整數股數、現金保留、佣金、稅、退出價差、淨報酬及同檔累積風險，再排序前三個有研究價值的候選。

普通歷史阻力仍是實際觀測價位。`MODELED_R_MULTIPLE_NOT_OBSERVED_PRICE` 則是另一種明確標示的模型情境，僅在已完成日線突破前 20 日高點、完成日線量能至少前五日均量 1.2 倍、趨勢條件成立且無更高可用結構阻力時使用；不能把這個估算宣稱為已觀測價格或未來保證價格。

趨勢情境持有觀察期限 10 個交易日、早期修復情境 2 日，仍保留到期重新評估與原假設失效時的退出判斷。這些參數尚未取得前向績效證明。

## 沒有為增加次數而移除的交易品質檢查

- 費後目標淨報酬至少 2%、淨報酬風險比至少 1.5。
- 設定 AI 資金 NT$10,000 時，同檔模型失效情境風險上限 NT$50。加碼會把舊部位於較保守失效價的風險、費稅一起算入，不會每輪重置額度。這是模型情境上限，不是實際損失保證。
- 目標情境淨利至少 NT$50，且至少為設定研究費用預算的 5 倍。研究預算目前設 NT$10，屬設計用的經濟性門檻，不是實際 API 帳單上限、匯率報價或統計期望獲利；真實 API 用量仍另行保存。
- BUY 需匹配目前重新計算的計畫；模型不能任意增加目標、貼近停損或放大股數。縮小股數後也須重新通過收益與研究成本門檻。
- 每筆 BUY 仍要兩方有效研究、獨立交易前審查、最新行情及正式券商檢查。advisory 的 WATCH 本身不否決，但具體重大反證仍可否決。
- 資金總額、單日買進上限、每筆 999 股、當沖限制、人工持股歸屬及正式帳本不變。已有未結單的標的不重複安排買進研究。
- 最終送單前再按當前股數、既有曝光、訊號層級上限、合併風險與更新行情重查。

## API 使用方式

保留使用者指定的每 60 分鐘掃描，日本時間 10:05～14:05。每輪先跑不呼叫模型的本機篩選。

- 有新的計畫族群、股數條件變化，或入場／目標／失效價有至少 0.3% 變化，優先研究。
- 沒有實質改變的進場計畫，至少隔 2 小時才重評；單純微小跳動或 hash 改變不會自動購買新分析。
- 沒有合格進場、也沒有 AI 持倉時不呼叫模型。
- 持倉股數、資金變化、至少 0.5% 價格變化或原計畫失效／目標觸及時優先重評。即使平穩，至少每 4 小時重看持倉；首個可分析交易時段仍會做新交易日檢查。
- 手動分析保留；狀態檔失效時會重新研究，不因快取問題永久抑制必要判斷。

風險觸發仍依每輪掃描取得的行情判斷，並非即時停損委託或全天候事件監控。第一輪若尚無有效 LIVE 零股行情，仍不會以試撮資料交易。

重播使用修復後的完整歷史日線，其中部分來源是在原快照之後取得；不是完全重建當時資訊集合的績效回測。沒有模擬為已成交，沒有宣稱提高勝率或已實現獲利，也沒有補送這些舊計畫。詳細數字及來源限制見 `opportunity_replay_20261103.json`。
