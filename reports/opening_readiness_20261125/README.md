## 通過條件後如何到下單

1. 全母體先計算既有支撐、目標、股數與費後條件。正式研究先取得可驗證零股行情及日內低點，失效位置須尚未被當天低點觸及。
2. researcher 與 challenger 獨立審查同一凍結資料，兩方都認可同一路徑才形成 RESEARCH_READY。WATCH 需要明確的重審條件，反證員不把尚待執行查核等同研究假說失效。
3. 正式流程會將 READY 交給執行工作；持股管理在忙時會保留新買佇列。再查券商帳戶、持股歸屬、未結委託、公司事件、即時行情、原計畫與經濟條件，並進行下單前模型複核。
4. 複核後重新取價及對帳，計畫入場、股數、失效與目標保持一致。計畫限價模式允許依原價掛單，不因 ask 尚高於原價就要求等到回落才掛單。
5. durable handoff 先保存防重送狀態，再交給既有正式執行器及 SendStockOddLotOrder。執行器再核對資金與風控；實際成交只依券商確認回寫，未知結果保留待對帳，不因沒看到成交就重送。

覆蓋的阻擋測試包含資金減少、持股改變、公司事件變更、過期／試撮／錯市場行情、複核改動股數、新低跌破失效價、計畫過期、跨交易日、停止、盤外、重複送單及回覆不明。這些阻擋對應資料或條件確實改變，應保留。

現行風控為單一部位含既有持股的模型損失上限 50 元、費後利益至少 50 元、費後報酬率至少 2%、報酬風險比至少 1.5，五個交易日期限。它們是交易資格與風險假設，沒有校準成獲利機率。最低保留額 5000 元是帳戶現金保留要求，不是每筆最低買進金額；新買可用額會隨正式對帳重新計算。
