2. **重算失敗可檢討與重審**：保存凍結／新重算值、報價、門檻、失敗項及複核前後階段；合法股數或計畫容量變化改變研究鍵，失敗後更新行情並重新雙審，不直接縮股替換已同意計畫，也不放寬風險。

4. **修正首次回報逾時丟失已登入 owner**（`c1391ef`）：實機新版啟動曾出現登入成功後 No OnComplete，舊程式只保留 2018 pending，其他此類逾時會丟掉已登入會話並永久保留錯誤。現在保留原 COM owner，下一輪先正常重設 Reply 通道，必須 Connect 成功、收到新的 OnComplete 並完整對帳才恢復；重設失敗仍封鎖，不再登入一次或忽略非零回碼。

群益官方將 2003 定義為「ID 已登入，無需重複登入」，不是密碼錯誤的證明。今日早先 2003 與本次 No OnComplete 應分開記錄；本次確認的是後者的會話保留缺陷，未宣稱已唯一還原午後全部斷線原因。[官方錯誤代碼表](https://www.capital.com.tw/apiforum/docs/errCodeDefinitions/)
