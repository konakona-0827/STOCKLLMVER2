## 更新與修正

遠端新版已提供完整可用完成日線、已存行情快照、同一券商會話收到的成交歷史及完成分鐘彙整，並區分 SYSTEM 系統缺口與 SOURCE 來源未回覆。快照不是分鐘 K，收到的成交也未認證為全市場完整成交。已確認本機安裝 SDK 有 `SKQuoteLib_RequestTicksWithMarketNo`；本次夜間仍需等盤中驗證真實成交及分鐘是否送達模型。

本次另外完成：

1. **計畫限價審核對齊**：雙代理評估既有入場、股數、失效與目標是否值得掛出計畫。現價尚未回到限價本身不再是固定 WATCH 前提；若型態未確認，仍須列出具體價格與時間證據。
2. **資料要求可達成**：advisory 模式不再把完整歷史回測認證、全部新聞歷史或 `continuous_coverage_verified=false` 單獨視為所有計畫永久觀望理由。具體公司事件影響及重大缺漏仍須說明，strict 原要求保持生效。未串接的資料直接標記缺口。
3. **新完成分鐘可觸發重審**：原快取將分鐘數封頂為 5，資料累積後若價格持平，新五分鐘也可能繼續沿用舊 WATCH。現在研究鍵加入最新實際收到的完成分鐘所在五分鐘窗；新窗可重審，相同資料仍沿用快取。這不是每五分鐘固定呼叫 LLM。

提示詞改為 `flow-review-v4-actionable-plan`，完整審核規則保存在 [提示詞指令](review_instructions.json)。兩方必須同意同一凍結計畫，之後仍要下單前複核、有效即時零股行情、新鮮帳務及原執行器風控。沒有強制把 WATCH 改成 BUY。
