行情根因

證交所已改用新的前端頁面 /stock/；舊 /stock/index.jsp 為 404，Referer 一併更新。
關鍵不是將 '-' 轉成 0，而是舊解析器只讀頂層 z、沒有支援官方的 tradeFallback。
頂層沒有成交價時，官方前端會採最近成交物件 trade.z 與 trade.t。
實查 11/16 官方 JSON 確實包含這組欄位；官方 JavaScript 直接實作相同回補。

官方來源：
https://mis.twse.com.tw/stock/
https://mis.twse.com.tw/stock/assets/tradeFallback-Du5LDleq.js
SHA256：a6debd9d7e137ea9085527a179bd24c0a47e0cfd136f385736cbaedcdf6dc255

新版優先使用有效的頂層成交；缺值才使用最近成交物件，成交價與時間成對取得。
保留原交易日期和時間；不以查詢時刻或 feed 的 14:30 時戳冒充新成交。
沒有有效最近成交時，回報 PUBLIC_LAST_TRADE_UNAVAILABLE；
沒有有效成交時間時，回報 PUBLIC_LAST_TRADE_TIME_INVALID。
不使用 pz、昨收或買賣中價填補，也不把整股參考價改標為即時零股。
120 秒資料新鮮度檢查與正式零股行情要求保持原狀。
fetch 另記錄 last_trade_fallback_count 與原始回應 SHA256。
