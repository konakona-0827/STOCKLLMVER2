## 流程的具體變化

| 層次 | 新系統 |
|---|---|
| 母體 | 官方上市、上櫃普通股名錄；缺漏也保留在母體 |
| 數值 | 先算型態、來源價位、股數與費後經濟條件，逐層留下原因 |
| LLM 輸入 | 精簡數值摘要、近八根 K 線、證據 ID、可選路徑、期限與已成熟歷史變幅；完整資料另外保存 |
| 頻率 | 30 秒輪替參考行情，每分鐘或資料改變時重算數值；背景每批三檔、兩次獨立審查 |
| 重審 | 重要價位跨越、價格變動達 0.3%、新資料／政策或四小時到期；相同事實不重複呼叫 |
| 資格 | 研究假說、價格等待、執行缺資料、錯誤分開；沒有把錯誤或未知寫成市場沒有機會 |
| 計畫 | 固定研究時的入場／目標／失效／股數；以新價差重檢，不能追著賣一價修改 |
| 執行 | 本版本沒有下單功能；公開整股參考價不作零股成交證據 |

正式舊系統的尋標上限 40、報價候選 6、每批研究 3、約每小時一次；已有快取及候選遞補。先前 selection_lab 的 22 檔是研究資料集，不是正式系統的全部母體。新系統沒有每日模型呼叫硬上限；批次大小是工作分配，服務失敗的退避也不是每日配額。

## 真實模型審查

使用既有 ChatGPT 登入的 `gpt-6-sol`，無 API Key、付費資料或 API 備援。每批兩個獨立角色讀相同 packet，互不讀對方意見。

- [固定 22 檔截點](cli_pilot_fixed22.json)：2 檔、2 次呼叫、73.687 秒，最後 2 檔 WATCH。
- [完整母體截點](full_market_cli_pilot.json)：6 檔、4 次呼叫、154.735 秒，最後 4 檔 WATCH、2 檔 REJECT。沒有雙方通過的計畫。
- [最終 transport 與 packet 實測](final_transport_pilot.json)：指定 4904 做 2 次呼叫、48.735 秒；仍為 WATCH。[相同事實一分鐘後再跑](cache_repeat.json)為 0 次模型呼叫、重用 1 份研究。

觀察原因已具體到期限、所需漲幅、近端高點、等待回落與價差未知。例如數值路徑通過，不代表模型認為五日內能重到目標。這次沒有為增加通過數而降低費後報酬、報酬風險或資金風險門檻。

本次尚不能證明兩週沒有交易主要由提示詞、頻率或資料型態造成。可以確認的是，新流程已能分開量測這些原因，且模型在背景判斷時不再阻塞行情主迴圈。
