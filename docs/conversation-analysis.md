# 使用者需求如何轉成台股研究架構

使用者提供的多代理交易桌文章是流程參考；其中鏈上代幣、錢包、合約地址與核准下單不直接移植。這次以使用者後續確認為準：維持台股，不介入日本行情；把 Advantest 例子的「已有反彈、回測確認支撐，價格仍值得研究」概念轉用於台股。

| 原文概念 | 這次的轉換 |
|---|---|
| Head 拆工作與維持關卡 | Python Head 排研究佇列、呼叫上限、稽核與固定裁決 |
| SEARCH 找線索 | 先以完整日線辨識支撐型態，再交研究員檢查論點 |
| RISK 審核 | 資料驗證、固定失效／距離門檻，加獨立反證員 |
| 同一編號與地址 | 同一 symbol、packet ID、快照、規則與 evidence ID |
| 不可跳過關卡 | 研究員與反證員缺一維持觀察，不能蓋過硬性條件 |
| 每日固定數量線索 | 依證據輸出，不設必須達成的筆數 |
| EXIT／SNIPER／核准／5% 停工 | 留待持倉與交易階段；目前只研究，不接帳戶 |

第一個型態叫「回撤後反彈再測」，不是把任何跌深都視為機會。它需要時間順序、固定支撐與現在距離；看到低價、單次長下影、熱門題材或模型互相同意，皆不足以獨立成立。

Advantest 不在本專案候選池，也未在這次用完整日線確認其近期支撐。未來人工提供的台股正反案例將用於判斷型態定義是否貼近需求，但不能只用幾個漂亮例子調參，必須另留樣本外檢查。
