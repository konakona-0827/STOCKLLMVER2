我認為這次應該重新思考整個 AI Agent 的交易方向，而不只是把原本的「一週獲利 1.5%～2%」改成一個月或一年。

因為你其實提出了兩種不同的競爭優勢：
1. 數量優勢： AI 能同時觀察幾百、甚至上千檔股票，頻繁尋找小額獲利機會，透過資金周轉累積收益。
2. 品質優勢： AI 能結合財報、新聞、產業趨勢、價格與成交量，找到人類不容易注意到的高潛力股票，等待更大的獲利。
這兩種方式都值得研究，但需要不同的預測模型、資料頻率、交易規則和 AI 呼叫方式。

我的初步建議是：把 3～10 個交易日設定為主要交易週期，20～60 個交易日作為趨勢判斷視野，同時建立一條獨立的 6～12 個月長期潛力研究線。

不必要求一個 LLM 同時負責所有時間尺度。

為什麼我比較看好 5～20 個交易日？
因為這個週期可能比較容易在三個因素之間取得平衡：
- 比一兩天的交易有更多時間讓趨勢發展。
- 比半年以上的投資有更快的資金周轉與策略驗證速度。
- 容許 AI 使用價格動能、成交量、產業輪動及事件資訊，而不只依靠極短線價格跳動。
但這不是說 5～20 日的市場預測一定比較準確。高頻研究發現，極短時間的價格與委託資料也存在可預測訊號，只是這類優勢高度依賴即時資料與執行速度；經典動能研究則發現，部分市場的 3～12 個月趨勢具有延續性。兩者使用的是不同資料與交易機制，不能直接拿來證明你的台股 BOT 在哪個週期最賺錢。

二、短期周轉真正的優勢與限制
你原本的想法其實很有邏輯：

如果一個人每天只能仔細追蹤 10 檔股票，AI 可以持續掃描 800 檔，那麼 AI 理論上可以捕捉到更多分散在不同股票上的短期機會。

但掃描量增加，不代表具有獲利優勢的交易數量也會同比增加。

還有一個很實際的問題：台股一般股票跨日交易，賣出證交稅為 0.3%；同日沖銷符合條件才有 0.15% 稅率。券商手續費另外計算。

這就產生一個值得研究的問題：

假設目標是 +1.5%，五天內達到目標的機率比較高，但成本占獲利也比較高。

假設目標改成 +3%，雖然單筆能賺更多，卻可能需要更長時間，而且成功率下降。

因此，最佳交易週期不一定是勝率最高的週期，而是扣除交易成本與虧損後，每單位資金、每單位時間能創造最多風險調整後收益的週期。

這才是我們接下來應該交給實驗系統回答的問題。
三、真正值得改造的是「多時間尺度 AI」
我不建議讓 AI 只選擇一週、一個月或一年其中一個時間範圍。

因為預測未來多久、打算持有多久、多久重新分析一次，應該是三個不同的參數。

例如：

假設一檔股票在未來三個月的產業前景很好，但接下來一週有財報風險。我們不應該因為長期看好，就忽略短期進場時機。

反過來說，即使某檔股票長期基本面普通，只要它未來三天存在短期交易訊號，也不應該直接排除。

我希望整個 Agent 能同時維持以下四層判斷。
Multi-Horizon AI Agent 架構
第一層：短期價格機會

3～10 個交易日

估計停利先於停損的機率、達標時間、短期波動與成交可行性。這是主要交易訊號來源。

第二層：中期趨勢

20～60 個交易日

判斷目前是上升、區間、衰退還是高波動狀態，協助選擇適合的短線策略。

第三層：產業與企業成長

3～12 個月

研究財報、營收、獲利預期、產業需求與資本支出，提供長期背景及中期候選標的。

第四層：交易與風控

盤中持續運作

根據最新價格及委託狀況執行停利、停損、資金限制與異常保護，不需要每次都等待 LLM 回應。


這種設計還有一個優點：我們可以研究某一層的判斷到底有沒有幫助。

例如，短線模型本來選出 50 檔候選股。如果加入中期趨勢與新聞過濾後剩下 20 檔，就可以比較被保留、被排除兩組的後續實際表現。

如果被排除的股票反而更賺錢，就說明過濾器有問題，應該修改或移除。

這比單純不斷讓 LLM 變得「更謹慎」可靠得多。
四、AI 到底要多頻繁呼叫？
這裡我反而不建議提高 LLM 的呼叫頻率。

提高行情掃描頻率，與提高 LLM 呼叫頻率，是兩件不同的事。

對你的系統，我建議初版如此安排：
模組	建議頻率	是否需要 LLM
行情與候選掃描	盤中每 5～15 分鐘	不需要
短期訊號更新	每 5～15 分鐘或事件觸發	量化模型

這些頻率是工程上的初始設定，實際還要配合群益 API 的行情權限、速率限制與資料更新速度。

例如：

系統掃描 800 檔股票，不代表要送出 800 次 LLM API 請求。

我們可以先讓程式利用技術特徵、波動率和成交成本，替 800 檔股票計算候選分數。

如果最後只有 30 檔具備值得研究的訊號，就將這 30 檔的結構化資訊分批交給 LLM，分析是否有重大消息或策略衝突。

而已經確認的停利、停損與下單規則，則由程式持續執行。

這樣能降低成本與決策延遲，也更容易發現究竟是哪個模型導致交易被拒絕。

值得注意的是，一項針對 LLM 投資策略的長期評估研究，發現部分策略在擴大股票範圍、延長評估期間之後，原先宣稱的優勢明顯減弱；研究也觀察到 LLM 在不同市場狀態下可能出現不適當的保守或積極行為。這支持我們不要把 LLM 的主觀交易信心當成唯一進場依據。

五、我建議正式展開三條平行實驗線
我們不應該現在就認定短線比較好或長線比較好，而是讓三種策略在相同的市場期間接受比較。

A：高周轉策略 — Quantity

主要預測期：3～5 日｜優先測試

專門搜尋短期有機會先觸及 +1.5%～2% 的股票。允許大量候選訊號、小額分散持有，並根據停損與趨勢提前退出。

主要研究：能否透過大量小額交易，取得穩定的正期望值？




B：中短波段策略 — Balanced

主要預測期：5～20 日｜我的首選對照組

加入趨勢延續、產業動能與事件訊號，不強制固定 2% 停利，而是依照預期收益、下行風險及持有時間選擇出場目標。

主要研究：提高交易品質後，是否能產生更好的資金效率？




C：成長潛力策略 — Quality

主要預測期：3～12 個月｜獨立研究

分析營收加速、產業趨勢、獲利預期變化與企業競爭地位。目的是研究能否更早辨認中長期高成長股票。

主要研究：增加深度研究是否能找到值得長期配置的標的？



起初，我會讓 A、B、C 使用獨立模擬帳戶，不直接混在同一個資金池。這樣才能明確比較哪一種策略真正有效。

等累積足夠的前向紀錄，再讓資金配置引擎決定不同策略的比例。
六、不要只預測報酬率，要預測「獲利路徑」
這是我希望下一代模型優先改善的能力。

以前 AI 可能只輸出：

「預計一週上漲 3%。」

但這對自動交易還不夠。

我們需要模型對每一檔候選股票輸出不同預測期限下的資訊：
模型輸出	具體意義
P(TP, 5D)	五日內先觸及停利的機率
P(SL, 5D)	五日內先觸及停損的機率
P(TP, 10D)	十日內先觸及停利的機率
E(Net P&L)	包含所有退出情境的預期淨損益
Expected Holding Days	預期資金占用天數
Risk / Regime	波動、產業相關性及市場狀態

這些數字必須由歷史樣本校準，而且要保留模型的不確定性。不能直接把 LLM 的「信心 85%」當成實際機率。

然後，資金配置就不必只看哪檔股票的預測漲幅最高。

例如有兩筆假設機會：
	股票甲	股票乙
預期淨收益	NT$240	NT$180
預期持有	12 天	4 天
每萬本金、每日預期收益	NT$10	NT$22.5

假設兩筆本金均為 NT$20,000，數據僅用來說明資金效率，並非真實預測。實際配置還要考量虧損分布及風險。股票甲的單筆預期收益較高，但股票乙能比較快釋放資金。

這正是你想發揮的 AI 自動化優勢：不斷比較所有候選機會，將有限資金配置到最值得使用的位置。
七、我們應該怎麼驗證哪個時間範圍最值得採用？
我建議採取三個階段。

第一階段：多期限歷史研究。 同時建立 3、5、10、20、60 個交易日的預測標籤。回測時應遵守當時可取得的資料、股票歷史成分、成本、委託撮合、T+2 交割與實際退出規則。對同時觸及停利停損的 K 線，必須有更細資料或採保守處理。

第二階段：獨立前向模擬。 三條策略同時運作，保留我們之前設計的 Experiment Registry、模型版本與決策紀錄。初期觀察 30～60 個交易日，主要確認執行可靠性與初步收益；中長期策略則必須累積更長時間才有足夠的評估資料。

第三階段：比較資金效率。 不只比較勝率，而是同時比較淨期望值、整體資產報酬、最大回撤、資金占用天數及相對大盤與買入持有基準的表現。

只有新策略在不同市場環境與樣本外資料中仍然維持優勢，才逐步增加模擬資金配置，之後再考慮是否進行小額實盤驗證。
