# 短線機會型態與路徑評估

0.10.0於2026-10-30加入，目標是增加可研究機會並辨識買入類型。仍只有尋標、研究、反證三個模型角色；Python計算參數、核對來源及部位。目標上漲2%不是已驗證的達標機率。

## 分類

| 型態 | 主要條件 | 解讀 |
|---|---|---|
| H-002 支撐試單 | 原近期低點守住／收復 | 沿用既有支撐與風報規則 |
| H-003 趨勢回檔 | 接近20日均線以上、5日線未明顯弱於20日線、回檔0.3–10%、近期低點守住 | 順勢承接 |
| H-004 站回／突破 | 收盤越過前三日收盤高點；或縮量守低、次日突破當日高點的條件式提案 | 確認突破與尚未觸發分開 |
| H-005 動能延續 | 收盤高於5日均線、接近前三日最高價、三日動能至少0.8%、收於日內上半部 | 不以距舊低點遠自動否決 |
| VOLATILE_WATCH | 五日區間至少6%、流動性足夠，進場型態尚未形成 | 值得觀察，不是買進結論 |

設定在 `config/patterns.json`、`config/opportunity.json`。共同下限包括20日平均日成交值5億日圓、相對量0.65、五日區間2%；單日漲幅超12%或三日超25%不作此版進場候選。這些是初始可調參數，未證明優於其他設定。

短線目標為實際參考進場價×1.02，觀察3／5個交易日，最多第5日重評或時間退出。非待觸發型態的次日參考上限為訊號價+1.5%；待觸發型態必須位於觸發價至上限之間，上限不超訊號收盤+10%。成交前按實際價重算，不能用過去低價假造今日可成交。

戰術價格停損初值1.5%，不是確認支撐。若小於ATR會明示容易被正常波動掃出；成本與額外0.5%跳空情境仍用於部位風險。選股採不計券商成本的策略風報至少0.8，價格2%目標與成本後估算分列。H-002保留原政策與歷史重播行為。

## 三角色交接

Python先掃描20檔所有型態，SEARCH在候選中選股；研究與反證各看同一組原始計畫，自行選最適型態。正向結果必須同一pattern_id、各自引用該型態required證據，任一否決不進場，型態不同則等待。待評估與已評估分列；高波動觀察也可交SEARCH研究，但不能因此升成已成立買訊。

短線純價量可以保留「未取回財報／公開搜尋未完成」背景缺口作人工核對；來源時間不明、晚於截止、引用不明或被排除仍阻擋。formal資格保留原限制。未勾選回報的建議不計入持倉。
