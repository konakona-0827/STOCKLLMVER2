# 交易時段掃描、延遲價與操作通知

2026-11-02依使用者要求啟用。仍是固定可配置20檔、尋標／研究／反證三角色，每輪最多研究4檔、9次模型請求。沒有下單或代填成交。

## 誰啟動程式

0.13.0已改成程式內部的ScanScheduler，原Codex排程已刪除。雙擊 `Dashboard.cmd`，或執行：

```powershell
python -X utf8 -m support_scout serve --port 8765 --open-browser
```

程式本身提供HTTP Dashboard及背景排程執行緒，不需Codex。控制台有啟動／停止按鈕、上次結果、是否分析中及下一次檢查時間；停止會寫入本機設定，重啟仍維持停止。頁面瀏覽器可以關閉，Python程式要保持執行，電腦有網路且不睡眠；關閉啟動程式的終端視窗也會結束程式。

重複啟動會開啟既有控制台，避免建立第二個掃描器。停止自動掃描不會中斷已在執行的分析。手動分析可明確重跑本半小時，仍遵守交易時段與互斥鎖；CLI是 `python -m support_scout session-scan --rerun`。`ScanNow.cmd` 則維持一般單次去重入口。

### 換電腦

1. 安裝Python 3.11以上、取得本專案；執行期只用標準函式庫。
2. 將 `local_settings.example.json` 複製成忽略的 `local_settings.json`，將 `.env.example` 複製成忽略的 `.env`，在本機填入自己的OpenAI key。ENV相對路徑以設定檔所在資料夾解析，搬動整個專案不必保留舊電腦使用者路徑。
3. Gmail寄件地址及應用程式密碼、本金／風險設定、確認成交紀錄是本機資料，需自行配置或搬移，不隨Git傳送；缺本金時不會建議正數部位。Gmail可用 `EmailSetup.cmd`，或明確用notify-configure引用本機ENV。
4. 雙擊 `Dashboard.cmd`；保持程式執行即可自動掃描。API設定檢查用 `python -m support_scout doctor --require-agents`，不呼叫付費模型。

## 時段與用量

日本時間09:00（含）至11:30（不含）、12:30（含）至15:30（不含），另排除週末與版本化JPX假日；未知年份拒絕推測交易日。每半小時只執行一次，先取得跨程序鎖並保留時段，防止重複喚醒或失敗後無限重試。休市／午休在行情、模型、郵件之前即回傳SKIPPED_MARKET_CLOSED。

每天通常有11個可執行的半小時時點。排程可能在午休或收盤邊界喚醒，但程式立即跳過，模型呼叫為0。午休剛結束時若Yahoo仍只有上午最後報價、超過30分鐘，會更新數值觀察並跳過模型，等下一輪；不把舊報價當新買訊。

## 延遲價如何參與

使用本輪新取得Yahoo回應的regularMarketPrice／regularMarketTime，重驗來源SHA256、股票身分、JPY與取得時間。不是讀舊快取做網路失敗備援，也不增加另一輪行情請求。報價不得晚於取得時間，取得時間不得晚於快照截止；完整時間、來源及延遲秒數送給三角色。最長可用延遲30分鐘，參數凍結在快照。

報價作為DELAYED_QUOTE證據，綁定本股票與本輪封包；正向型態required引用包含它。模型仍看完整日線型態，不能以單一延遲價聲稱今日收盤已確認、已放量突破或可保證成交。過期／缺報價阻擋買入提案，高於進場上限也等待。

非待觸發短線計畫用延遲價重算參考進場、2%價格目標及1.5%戰術風險線，進場上限兼顧原型態上限與報價+1.5%。待觸發計畫保留觸發價；若在區間其他價位實際進場，目標及風險線須重算，郵件也列區間上端的重算情境。H-002的結構支撐保持固定，僅重核報價距離與風報。成交後不得自行下移風險線。

研究JSON上限自28,000調至36,000 bytes，容納延遲價證據與共用來源事實，避免先前信越反證輸入超額；仍作無損精簡、不截證據、不放寬引用或來源時間檢查。上限調整不代表每次用滿，也不是token預付費。

## 哪些事件寄信

| 事件 | 郵件 |
|---|---|
| WATCH、WAIT、AVOID、NO_TRADE、HOLD、資料待核對 | 不寄，即使含參考價 |
| 三角色支持的PROBE_BUY_REVIEW／正式CONSIDER | 須有正數建議金額及有效進場、風險與目標才寄 |
| ENTRY_REVIEW人工進場評估 | 須對應上述有效買入提案才寄 |
| EXIT_REVIEW／REDUCE_REVIEW | 須有使用者已確認的持倉數量才寄 |
| 歷史／合成測試 | 不寄 |

郵件列標的、條件式買入區間、觸發價、風險價、目標、建議金額／換算股數及報價時間。未觸發仍只是提案，須人工核對券商即時價及資格。等待會撤銷舊未寄提案；同狀態不重複。舊佇列WATCH在寄送前抑制，SQLite也拒絕舊版頁面服務再寫入非操作事件，避免程式尚未重啟時恢復寄等待信。

歷史已寄信不刪除，保留稽核。Gmail地址與密碼引用沿用本機忽略設定，不在版本庫或訊息輸出憑證。
