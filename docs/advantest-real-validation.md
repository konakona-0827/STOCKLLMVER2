## 時點界線

今日下載的歷史日線不是歷史當時快照。工具保留每根日線真正 `available_at` 與原始 JSON SHA256，不把取得時間改成過去；每個輸入另以 `analysis_context.market_data_cutoff` 截斷價格，報告 `as_of` 保留實際分析資料取得時間。所有UI明示「真實行情前綴的事後重算」，不稱當時決策或PIT回測。歷史案例禁止即時web搜尋，不寫正式SQLite帳本，也不帶入真實持倉。

## 執行介面

`support_scout.advantest_case.run_real_case()` 回傳 `(comparison, output_folder)`；預設只做數值案例，會取一輪Yahoo及官方文件。可注入已保存 `source_bundle`、`documents` 及fake provider，方便離線測試；不讀或輸出金鑰。`agents=True` 由既有本機設定接OpenAI，每截點最多搜尋一次加研究／反證各一次，總上限預設9。

若正式數值門檻根本沒有候選，正常SEARCH不應假裝命中。可明確指定 `diagnostic_review=True`，讓研究／反證各讀原始canonical packet一次，記錄在 `diagnostic_reviews`／`diagnostic_audit`，不輸入正式裁決、不改閘門、不稱三角色完整尋標。診斷模式每截點最多2次，額度不足不啟動半對。

保存內容包含案例參數、原始來源bundle、官方文件metadata、逐日截斷輸入、完整報告、AI評語、比較HTML、SHA256 manifest。`replay_real_case(folder)` 完全離線驗證來源摘要、截斷輸入與數值／裁決一致性。

需要分開閱讀三件事：H-001是否提早列機會、尋標agent有沒有正式提交、最終是否有足夠資料建議交易。沒抓到時應從穩定期數、區間寬度、支撐測試、流動性／量能口徑與ATR閘門找原因，不能藉調參或刪blocker把這個已知結果改寫為成功。
