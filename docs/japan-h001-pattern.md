# H-001：支撐穩定後的催化反轉

機會研究層依使用者2026-10-29提供的GPT對話建立，現已整合回指定分支 `codex/japan-support-desk-phase1`。仍維持SEARCH、研究員、反證員三個角色；Head與固定檢查由程式執行。真實Advantest案例與結果另見[真實驗證](advantest-real-validation.md)，下列合成案例不冒充真實命中。

## 假說與界線

H1 問的是「下跌後低點穩定」是否與一般連跌股票有不同後續表現；H2 再問「有可核對的正面超預期催化」是否優於沒有催化的穩定組。這兩個假說尚未通過歷史與樣本外驗證。來源對話的 43%、54%、67% 是假設示例，不輸入模型作為勝率。

`config/patterns.json` 保存版本、處理器、參數、假說與未來 1/3/5/10 個交易日的評估期限。可停用定義或新增已實作的處理器，不依單一股票寫死規則。初始門檻是研究用設定，沒有針對真實 Advantest 最佳化。

目前 H-001 v2 的主要參數：前20期高點回撤至少8%；至少3個交易日無新低，觀察5期穩定範圍；支撐帶為低點±1%，成立後固定；至少2次間隔2期的支撐測試；穩定期量能不超過前10期均量的0.8倍；突破前5期高點及量能至少1.3倍；距支撐帶上緣最多5%；催化有效7日，超預期至少5%。具體計算與全部數值以版本化JSON為準。

| 階段 | 意義 |
|---|---|
| EARLY_WATCH | 低點穩定，但仍缺較強支撐或催化證據 |
| SUPPORT_STRENGTHENED | 支撐測試與縮量等條件增強 |
| CATALYST_AWAITING_PRICE | 可見正面超預期事件，但缺可辨識的公布後價格確認 |
| CATALYST_CONFIRMED | 再有公布後的新交易日與突破／量能條件，仍不證明因果或獲利能力 |
| INVALIDATED / UNDERCUT_REVIEW | 固定區間失效，或盤中下探需重核 |
| EXTENDED / CONTRADICTED / EXPIRED | 位置過遠、基本面反證或情境過期 |

重複測試支撐不代表獨立統計樣本。日線不能重建盤中先後；同日價格保守地不算財報公布後反應，即使公告在盤中。基本面惡化是反證，不能把所有大跌都當便宜。

## 與原本決策模型並行

原本 `technical` 使用嚴格 ATR 支撐、另日反彈、另日回測、再確認；H-001 使用百分比支撐與機會階段。兩者是不同研究定義，不能混用支撐價或失效價。H-001 早期線索可交給 SEARCH，不必等原ATR模型完全確認，但不覆寫原本交易閘門。

H-001 目前在可見歷史內因果凍結支撐並保留終止情境；跨日SQLite帳本仍追蹤原ATR模型，尚未建立H-001獨立實盤生命週期。

## 財報與新聞主動研究

日股 `observe --agents` 的SEARCH預設從可配置20檔研究池形成候選並提交標的，JPX廣域母池改為明確選用。0.7.0預設 `shared_once`：研究員以有界OpenAI `web_search`查決算、業績修正與新聞，反證員用相同來源事實查找需求、一次性收益、展望下修與已反映風險，不看到研究員結論。反證員沒有另做獨立檢索；如選 `independent` 政策才各自檢索，會增加工具用量。不新增第四個角色。

設定在 `config/public_information.json`：每個執行檢索的角色每檔最多3次工具呼叫、6項事實、120日發布窗口。`--max-calls`控制模型請求數，工具次數另記。例如1次SEARCH加4對研究／反證，模型最多9次；shared_once最多12次工具，independent最多24次。呼叫上限不是金額預算。

每個角色的 `public_information` 保存工具動作、工具實際來源URL與引用、模型抽取的發布時間、事實、期間、比較基準、支持/反對方向、排除原因與摘要雜湊。無完成工具紀錄不能宣稱已搜尋；沒有查到原始財報/展望則保留WATCH。搜尋部分失敗時保存已完成來源，未執行動作的URL不算已讀；完成次數超過政策則排除事實並降級，沒有自動重試。API可能在額度用完後留下未執行的尾端嘗試，因此完成次數與嘗試次數分開記錄；有未完成部分仍保守WATCH。

URL必須出現在 hosted search 的來源、開啟動作或引用紀錄內；這只能證明模型接觸過該連結，**不證明內容、發布時間、公司主體或抽取數值正確**。模型對來源類型的分類也尚未經獨立驗證。每項事實保留此限制，不自動轉成 `verified=true` 的H-001事件，不解除公司事件、PIT或交易狀態的硬性缺口。

精確公告時間不得晚於截點；只有日期的資料保守視為日本時間該日結束才可用，同日時間不明者排除。即時搜尋只允許真實日股、截點距取得時間最多24小時；合成案例與歷史截點不連外搜尋。今日可查到舊公告也不代表還原了歷史當時資訊集。網頁是外部資料，任何指令均不採用。

公司上修、同比成長與超市場預期必須分開；缺公告前同期間、同口徑的一致預期來源，不得宣稱超預期。已驗證的結構化H-001催化輸入另外要求實際值、預期、單位、事前可得時間、公告時間與來源。

```powershell
python -m support_scout observe --agents --max-packets 2 --max-calls 5
# 明確只做價量與快照研究，不開啟外部搜尋
python -m support_scout observe --agents --no-public-information --max-packets 2 --max-calls 5
```

程式直接呼叫 `observe(...)` 時，可用 `public_information=True` 啟用；提供已保存bundle時預設保留原政策。一般 `desk` 入口只遵循輸入中已凍結的政策，不偷偷替歷史輸入開啟網路。

工具接法依 [OpenAI web search官方文件](https://developers.openai.com/api/docs/guides/tools-web-search) 與 [Responses呼叫上限說明](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)。

2026-10-29另以Advantest公司身分、沒有行情的獨立診斷packet實測查找：研究員找到官方決算review、IR資料庫與相關新聞，反證員亦獨立回傳來源；最終檢查各保留5項與6項抽取，並保留時點未知及未完成工具嘗試的缺口。兩方均WATCH，沒有產生真實支撐判斷。共3次模型請求，含初次反證處理失敗後為修正工具計數而手動重驗1次；正常工作流程無自動重試。兩次已保存成功回應合計59,042 tokens，失敗處理的用量未知，不能把它當0，也不能直接由此推估每日固定費用。

## Advantest 人造參數實驗

`cases/advantest_h001.synthetic.json` 明示所有 OHLC、量能、盈餘與預期都是人造值，30,000日圓只取作情境基準。這不是對真實歷史價格或財報的查證。規則於2026-10-29建立，早於此日的截點只是明示的事後參數實驗，沒有聲稱當時已有策略，更不是有效歷史績效回測。

六個截點依次測試：初期穩定、支撐縮量、收盤後催化待價格、下一交易日確認、追高對照、跌破對照。未公布事件及未來行情不進入早期packet；預期階段只在測試斷言中，不餵給模型。

```powershell
# 無API、無金鑰的數值檢查
python -m support_scout pattern-case
# 四個正向截點各SEARCH+研究+反證，合計最多12次；兩個負向對照不花模型額度
python -m support_scout pattern-case --agents --max-total-calls 12
# 可只測一個階段
python -m support_scout pattern-case --agents --checkpoints support --max-total-calls 3
# 已保存結果完全離線重播
python -m support_scout pattern-case-replay output/pattern-cases/<run_id>
```

每次建立獨立資料夾，包含原參數紀錄、截點輸入、完整packet、已保存模型裁決、HTML比較與雜湊manifest；不寫入正式SQLite觀察帳本。重播驗證輸入、數值階段、搜尋綁定與裁決，不再呼叫模型。

2026-10-29 的v2實測完成12次模型請求：四個正向截點都由三角色處理，兩個獨立決策角色均保留WATCH；它們能區分穩定、縮量、催化待價格與公布後確認，但沒有把合成證據升為真實買點。追高與跌破對照為NO_TRADE。初版實測的反證員發現「收盤後財報不能解釋當天日線」問題，已形成v2修正與回歸測試。保存結果離線重播MATCH。
